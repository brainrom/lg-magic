# Драйвер LG Magic Remote (MR20) для Linux

**Язык:** [English🇬🇧](README.md) | **Русский🇷🇺**

![LG Magic Remote](images/lg_magic_remote.png)

## Описание

Драйвер ядра Linux для пульта LG Magic Remote (MR20 и аналогичных).
Обеспечивает назначение кнопок, управление указателем и доступ к сырым данным
IMU. Также доступен опциональный подпроект голосового ввода.

## Возможности

### Кнопки

Цифровые клавиши, навигация, медиа-клавиши, цветные кнопки и функциональные
клавиши. В кнопочном режиме колесо работает как UP/DOWN.

### Аэромышь

Аэромышь работает без дополнительной калибровки: драйвер использует SCD
(Sensor Calibration Data) самого пульта и оценивает смещение гироскопа во
время работы. Встряхивание включает режим аэромыши. В режиме указателя колесо
отдаёт обычные события прокрутки, а кнопка колеса — `BTN_LEFT`. Нажатие любой
кнопки, кроме кнопки колеса, возвращает кнопочный режим.

Чувствительность и порог встряхивания настраиваются для каждого устройства.
Для повышенной точности доступен опциональный per-unit калибровочный блоб.
Подробности — в [docs/airmouse.md](docs/airmouse.md).

### Данные IMU

Сырые данные IMU (Inertial Measurement Unit) — акселерометра
и гироскопа — отдаются отдельным устройством ввода, если
модуль загружен с `imu_evdev=1`.

### Голосовой ввод

Опциональный подпроект голосового ввода: привилегированная служба, источник
WirePlumber/PipeWire и опциональный FIFO. Установка и описание — в
[voice/README.md](voice/README.md).

## Установка

### Требования

- Заголовочные файлы ядра Linux;
- DKMS (для установки через DKMS);
- Инструменты сборки (`make`, `gcc`).

### Ручная сборка

```bash
make -C kernel
sudo insmod kernel/lg_magic.ko
```

### DKMS

```bash
sudo mkdir /usr/src/lg-magic-1.0
sudo cp * /usr/src/lg-magic-1.0/
sudo dkms add -m lg-magic -v 1.0
sudo dkms build -m lg-magic -v 1.0
sudo dkms install -m lg-magic -v 1.0
```

## Настройка

### Параметры модуля

Это **значения по умолчанию, применяемые при подключении устройства**. Для
настройки во время работы используйте атрибуты sysfs конкретного устройства.

```bash
sudo modprobe lg_magic airmouse=1 airmouse_threshold=300 \
    sensitivity_x=600 sensitivity_y=600 imu_evdev=1 debug=2
```

| Параметр | Единицы | По умолчанию | Значение |
|---|---|---|---|
| `airmouse` | 0/1 | 1 | Включить режим указателя при подключении устройства |
| `airmouse_threshold` | °/s | 300 | Порог встряхивания |
| `sensitivity_x` | px/rad | 600 | Горизонтальная чувствительность |
| `sensitivity_y` | px/rad | 600 | Вертикальная чувствительность |
| `imu_evdev` | 0/1 | 0 | Отдавать сырые данные IMU как отдельное устройство ввода |
| `debug` | 0-2 | 1 | Уровень отладочной информации модуля ядра |

### Sysfs

Атрибуты находятся в каталоге HID-устройства. Найти их можно так:

```bash
ls /sys/bus/hid/devices/*/airmouse
```

| Атрибут | Доступ | Единицы | Значение |
|---|---|---|---|
| `airmouse` | rw | 0/1 | Включить режим указателя |
| `airmouse_threshold` | rw | °/s | Порог встряхивания |
| `sensitivity_x` | rw | px/rad | Горизонтальная чувствительность |
| `sensitivity_y` | rw | px/rad | Вертикальная чувствительность |

Диагностические атрибуты (`fw_version`, `fw_major`, `fw_zone`,
`battery_level`, `scd`, `motion`) находятся в том же каталоге.
